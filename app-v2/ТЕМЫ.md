# Темы v2 — как переключать скин (текущий: С2-голд «Полночь и золото», с 25.07)

Весь вид держится на токенах. Смена темы = замена значений ниже в 4 местах
(cabinet.html + index.html `:root`, v2-app.js `:root`, плюс автозамена остатков
rgba). Откат С2 → С1 — обратная замена, ~2 минуты. Формы (радиусы, шрифты)
меняются теми же блоками.

## Где лежат токены
1. `cabinet.html` и `index.html` → `<style>` `:root` (палитра движка) + фон html + вуаль + v2-design блок (шрифты/кнопки/радиусы).
2. `v2-app.js` → `:root{--v2-*}` (табы, «Сегодня», лента дней).
3. `workouts.js`, `v2-ui.js` → используют var(--accent...) + свои rgba-линии.

Остальные наборы токенов (С3 светлый, С4 медь, С5 лайм) — в
`дизайн-макеты/стиль-С*.html`, блок `.sX{...}` каждого файла.
