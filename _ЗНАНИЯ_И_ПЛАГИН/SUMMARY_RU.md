# Сводка проекта — версия для российского рынка (как есть)

Это обзор работающего веб-приложения «Калькулятор КБЖУ + план питания на 28 дней» для
фитнес-тренера. Написан как читаемый рассказ: что это, на чём держится, какие функции.
Технические детали и формулы — в `MOBILE_APP_MASTER_PROMPT.md`.

## Суть продукта

Клиент за минуту получает персональную суточную норму калорий и Б/Ж/У и готовый план питания
на 28 дней. Каждый день — 4–6 приёмов с конкретными рецептами, точными граммовками и КБЖУ,
попадающими в норму с точностью ±1.5% по калориям и ±3% по белкам/жирам/углеводам. Клиент
листает блюда, исключает нелюбимые ингредиенты, фиксирует понравившиеся, отмечает съеденное
и получает список покупок.

Продукт разделён на бесплатную витрину-воронку (расчёт КБЖУ и пробный план) и платный личный
кабинет, который открывается после оплаты 299 ₽ и хранит профиль и прогресс на сервере.

## На чём держится

Приложение — два одностраничных файла на чистом JavaScript (без фреймворков): витрина и
кабинет, зеркала друг друга. Вся тяжёлая логика считается прямо на устройстве клиента, без
обращения к серверу: расчёт нормы, подбор блюд, балансировка дня. Сервер нужен только чтобы
проверить оплату и хранить профиль/прогресс.

Данные лежат рядом статическими файлами: база из 3746 рецептов с уже посчитанными порциями под
шесть весовых групп, справочник КБЖУ на 1287 ингредиентов, микронутриенты, и 238 «якорей» —
готовых 28-дневных раскладок под типовые профили. Фото блюд (по одному на рецепт) раздаются
из хранилища.

Хостинг — Yandex Object Storage (статический сайт). Бэкенд — одна серверлесс-функция Yandex
Cloud плюс база YDB, доступ через API Gateway. Оплата — Продамус. Приложение работает как PWA
(ставится на телефон как иконка) и умеет тихо обновляться само, когда выходит новая версия.

## Как считается норма и строится план

Норма калорий считается по формуле Миффлина–Сан-Жеора (базовый обмен) с поправкой на
активность и цель: при похудении щадящий дефицит, при наборе умеренный профицit, плюс
физиологические «полы» калорий и защита минимума углеводов и жиров. Белок и жир считаются по
коэффициентам на килограмм с потолками и коррекцией при ожирении. Это согласованная с тренером
медицинская логика — числа менять нельзя.

План на 28 дней собирается из «якоря» — готового пресета под профиль клиента, который движок
достраивает под точную норму: масштабирует порции и, если надо, заменяет отдельные блюда,
добиваясь ±3%. Блюда ранжируются так, чтобы чередовались типы (не идут пять оладий подряд),
не повторялись между соседними днями и не превышали безопасные верхние пределы по
микронутриентам (отдельная защита здоровья — например, ограничение печени по витамину A).

## Функции

Расчёт КБЖУ и прогноз темпа; план на 28 дней; листание-замена блюд с сохранением баланса дня;
исключение любых ингредиентов; фиксация блюд и числа приёмов замком (переживает перезаход);
отметка съеденного; список покупок; голосовой/текстовый подбор блюд; синхронизация профиля и
прогресса между устройствами; вход по email и номеру заказа; продление подписки со стыковкой
срока.

## Оплата и доступ

Доступ — 31 день за 299 ₽. Клиент платит на готовой странице Продамуса, получает письмо с
номером заказа и входит по email + этот номер. Продление приклеивает новый месяц к концу
текущего срока (оплаченные дни не сгорают); после продления вход только по новому номеру
заказа. Все правила доступа — на сервере, клиент их подделать не может.

## Что важно помнить при развитии

Рецепты берутся только из реальных проверенных источников и переписываются оригинально —
не выдумываются. В базе не должно быть «варёных» продуктов: вся варка показывается в шагах
через сырой продукт и воду, иначе врут и вес блюда, и калории. Любая правка данных требует
пересчёта порций и микронутриентов офлайн-скриптами и повторной сборки затронутых пресетов.
